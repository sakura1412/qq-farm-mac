# QQ经典农场监控 · Mac 分享版

在 Mac 微信电脑版中，自动识别「QQ经典农场」好友列表里的 **手掌＋黑色面罩** 可偷菜标识，拜访对应好友并执行「一键偷菜」。每位使用者登录自己的微信，工具使用当前小程序中的好友列表。

这是社区脚本项目，**不是腾讯或微信官方项目**。工具没有独立账号系统，不接收微信密码或验证码；扫码、手机确认和账号登录均由微信完成。

## 下载与首次使用

前往 [GitHub Releases](https://github.com/sakura1412/qq-farm-mac/releases/latest)，下载 **`QQ农场监控-Mac-1.0.0.zip`**，解压后使用。请下载发布页的这个安装包；GitHub 自动生成的 `Source code` 压缩包是源码。

| 条件 | 说明 |
| --- | --- |
| 设备 | macOS，已安装微信电脑版；当前不支持 Windows、手机或浏览器 |
| Python | 启动器探测 Python **3.9–3.13**，推荐安装 **3.12 或 3.13**；更新版本尚未验证 |
| 网络 | 首次启动需要联网下载运行依赖，之后复用本机环境 |
| 系统权限 | 给实际运行脚本的终端开启「屏幕录制」和「辅助功能」 |
| 游戏状态 | 登录自己的微信，打开「QQ经典农场」，保持游戏窗口可见 |

1. 解压**整个**「QQ农场监控-Mac」文件夹，双击里面的 **`开始使用.command`**。不要只移动启动文件；文件夹路径可以包含中文或空格。
2. 启动器检查 Python 并自动准备依赖。没有合适的 Python 时，到 [Python 官方 macOS 下载页](https://www.python.org/downloads/macos/)安装 Python 3.12 或 3.13，再打开启动文件。安装过程中保留终端窗口，等待完成。
3. 工具会打开微信。按微信正常流程登录自己的账号，手动打开「QQ经典农场」，进入 **「好友」→「同玩好友」** 列表。
4. 在 **系统设置 → 隐私与安全性** 中，为运行脚本的终端开启 **「屏幕录制」**（部分系统显示「屏幕与系统音频录制」）和 **「辅助功能」**。双击启动文件通常由 Terminal（终端）运行；如果用 iTerm 等软件启动，就授权该软件。
5. 授权后用 **Command+Q 完全退出终端**，再打开 `开始使用.command`。仅关闭一个终端窗口可能无法让权限生效。
6. 游戏准备好后，按提示回车。检查和正式运行前有 **5 秒准备时间**，把终端移到游戏旁边，确保没有遮挡游戏。监控开始后，在运行脚本的终端按 **Ctrl+C** 停止。

如果 macOS 阻止打开下载的启动文件，使用系统提示或「系统设置 → 隐私与安全性」中针对这个文件的允许打开操作，确认来源后继续。此包是脚本包，尚未作为签名的 Mac App 分发；无需关闭系统安全检查。

## 自动监控的行为

- 扫描当前页的可偷菜标识，点击标识同一行的「拜访」。**不依赖或记录好友昵称**；文字识别用于定位「好友」「同玩好友」「拜访」等固定控件。
- 进入好友农场后，根据「可摘」标记执行「一键偷菜」，然后回家，重新打开好友列表并从顶部继续扫描，处理互动后排序变化。
- 当前页没有标识时继续向下翻页；到达底部后从顶部再复核一次。
- 每轮扫描结束后，默认等待 **180 秒**再开始下一轮。这是轮间等待时间，每轮本身的耗时取决于列表长度和采摘次数。
- 同一行持续有标识却无法采摘、微信要求重新登录、页面无法确认或达到巡查上限时，会记录原因并停止，避免反复空转。

运行记录统计**拜访次数和采摘操作次数**，不统计不同好友人数。采摘后可能再次检查同一好友。

运行期间保持 **Mac 唤醒、解锁**，游戏放在**主显示器**且完整可见。不要移动或缩放农场窗口、遮挡游戏、同时手动操作游戏，或启动第二个监控进程。工具会检查重复启动并阻止并行操作。游戏界面明显变化时，模板可能需要更新。

## 配置、日志和账号数据

使用 `开始使用.command` 或 `portable_bootstrap.sh` 时，本机数据默认保存在：

```text
~/Library/Application Support/QQFarmMonitor
```

| 文件或目录 | 用途 |
| --- | --- |
| `config.json` | 当前 Mac 的配置；首次运行从公开默认配置生成 |
| `farm.log` | 识别、巡查和采摘日志 |
| `launch-public.log` | 通过 `开始使用.command` 启动时的安装及运行输出 |
| `friends-status.json` | 最近一轮的匿名操作记录、统计和完成状态 |
| `environments/` | 自动安装的 Python 依赖环境 |

在本机 `config.json` 中，`interval_seconds` 控制轮间等待秒数，默认 `180`；`region` 默认 `null`，每次启动自动寻找自己的农场窗口。停止监控后再修改配置，下次启动生效。

每位使用者的配置、日志和依赖保存在自己的 Mac。分享包不包含分享者的微信会话、个人配置、日志或截图。无需把微信账号或密码写入任何配置文件。

高级用法可通过环境变量 `QQFARM_DATA_DIR` 指定另一数据目录：

```bash
QQFARM_DATA_DIR="$HOME/QQFarmData" zsh portable_bootstrap.sh
```

## 检查、单轮运行和当前好友模式

在解压后的「QQ农场监控-Mac」目录打开终端，使用以下命令。它们会准备或复用运行依赖；首次安装仍需要联网。

```bash
# 检查依赖、权限和农场窗口；不打开微信或操作游戏
zsh portable_bootstrap.sh --diagnose

# 完成登录引导后，仅识别游戏画面，不采摘
zsh portable_bootstrap.sh --check

# 完成一轮全好友巡查后退出
zsh portable_bootstrap.sh --once

# 只监控当前打开的好友农场；先手动进入该好友农场
zsh portable_bootstrap.sh --current

# 只处理当前好友一次
zsh portable_bootstrap.sh --current --once
```

## 常见问题

| 现象 | 处理方法 |
| --- | --- |
| 没有找到可用的 Python | 安装 Python.org 提供的完整 Python 3.12 或 3.13，再重新启动；启动器需要 `venv`、`ensurepip` 和 SSL |
| 依赖下载失败 | 查看终端报错，检查网络后重新启动；若提示证书问题，运行 Python.org 安装目录中的 `Install Certificates.command` |
| 已授权但仍提示权限缺失 | 确认授权的是实际使用的终端，Command+Q 完全退出后重开，再运行 `--diagnose` |
| 未找到农场窗口 | 在微信内打开小程序，放在主显示器，保持完整可见；运行 `--diagnose` 检查 |
| 未确认游戏画面或页面不匹配 | 恢复正常游戏页面，优先停留在「同玩好友」列表，移开遮挡窗口，再运行 `--check` |
| 提示已有监控进程 | 在原来的运行终端按 Ctrl+C 停止，再重新启动 |
| 同一行有标识但无法采摘 | 先手动核对好友农场实际状态，查看 `farm.log`；不要反复启动异常页面 |

## 从源码运行

需要本机已安装 Git 和符合上述范围的 Python。在终端执行：

```bash
git clone https://github.com/sakura1412/qq-farm-mac.git
cd qq-farm-mac
zsh portable_bootstrap.sh
```

也可以在 Finder 中双击源码目录内的 `开始使用.command`。两种入口都采用相同的登录引导、权限检查和本机数据目录。

## 构建分享包

打包程序仅使用 Python 标准库，不需要安装游戏识别依赖：

```bash
# 检查发布文件是否齐全
python3 build_release.py --check-only

# 生成 ZIP 及 SHA-256 校验清单
python3 build_release.py
```

输出位于 `dist/`，版本号来自 `VERSION.txt`。打包采用明确的文件允许名单，并重新生成公开默认配置；不会复制 `.venv`、本机运行环境、个人配置、日志或截图。分享时发送生成的完整 ZIP，不要直接压缩自己的工作目录或用户数据目录。

## 验证范围

目前已在开发者的一台 Mac 上确认全好友巡查和自动采摘可以运行。分享版 1.0.0 发布前通过 **69 项自动测试**和 **15 项启动安装模拟场景**，并检查了打包名单、默认配置、启动文件权限及含中文和空格的路径。

另一台 Mac 上的微信登录、权限授予和游戏整轮运行尚未完成实测。首次使用建议在旁观察一轮，确认可偷菜标识与拜访按钮对应正确。不同的游戏界面、窗口布局或后续小程序更新可能需要调整识别模板。

源码中的测试可在已安装依赖的 Python 环境运行：

```bash
python3 -m unittest discover -p 'tests_*.py'
```

依赖本地图像的测试使用 `QQFARM_TEST_LIST_IMAGE` 和 `QQFARM_TEST_FARM_IMAGE` 指定测试者自己的截图；未提供时跳过对应图像测试。请勿将包含好友昵称、头像或账号信息的截图提交到公开仓库。
