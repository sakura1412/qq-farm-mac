QQ经典农场监控 — Mac 分享版 1.0.0

每位使用者先在自己 Mac 的微信里登录自己的账号，再打开 QQ经典农场使用。
此分享版没有独立的注册、收费或云账号系统。程序不保存微信密码或登录凭证，
也不复制分享者的微信会话；好友列表来自使用者当前登录的小程序。
使用本工具无需另外填写用户名或密码，按微信自己的扫码/手机确认流程登录即可。

这是可分发的脚本包，不是已签名的 Mac App。
支持 macOS 上的微信电脑版；此包不支持 Windows、手机或浏览器运行。

首次开始使用

1. 解压 ZIP，把整个“QQ农场监控-Mac”文件夹放在方便的位置。
   不要单独移动其中的启动文件；目录名称可以含空格或中文。

2. 双击“开始使用.command”。启动引导会检查 Python 和运行依赖。
   首次安装需要联网，安装期间保留终端窗口，不要重复启动。
   如果没有可用的 Python，按终端提示到以下官方网站安装 Python：
   https://www.python.org/downloads/macos/
   推荐 Python 3.12 或 3.13。安装后重新打开“开始使用.command”。
   启动器兼容探测 Python 3.9 至 3.13；更新版本尚未验证。

3. 在这台 Mac 的微信里正常扫码或确认登录自己的账号。
   在微信内手动打开“QQ经典农场”，进入“好友”→“同玩好友”列表。
   登录和打开小程序由微信完成；程序不会代替你输入密码或验证码。

4. 给运行脚本的终端开启 macOS 权限：
   系统设置→隐私与安全性→屏幕录制（部分版本显示“屏幕与系统音频录制”），
   开启“终端”；系统设置→隐私与安全性→辅助功能，也开启“终端”。
   如果使用 iTerm 等终端软件，则授权实际运行脚本的那个软件。
   授权后用 Command+Q 完全退出该终端，再双击“开始使用.command”。
   只关闭一个终端窗口通常不足以让权限生效。

5. 按终端提示检查权限与窗口状态，然后开始全好友监控。
   开始后有 5 秒准备时间，把终端移开，保持农场窗口可见。
   在运行中的终端按 Ctrl+C 即可停止。

如果 macOS 阻止打开下载的启动文件，按照提示在“系统设置→隐私与安全性”
对这个文件使用系统提供的允许打开操作，并确认来源是你信任的分享者。
不要关闭系统安全检查，也不需要执行批量清除隔离属性的命令。

监控如何运行

程序直接识别好友列表里“手掌＋黑色面罩”的可偷菜标识，并点击同一行的
“拜访”。进入好友农场后执行“一键偷菜”，回家并重新扫描列表。
没有标识的当前页仍会继续向下滚动；采摘后从顶部重新检查，处理列表排序变化。
到达底部后再次从顶部复核。本轮结束后默认等待 180 秒，再开始下一轮。

程序不依赖或记录好友昵称。文字识别只用于定位“好友”“同玩好友”“拜访”
等固定控件。运行记录统计拜访次数和采摘操作次数，不统计不同好友人数。
如果同一候选持续有标识却不能采摘，或遇到登录失效、页面不匹配等情况，
程序会说明原因并停止。不要在异常界面上反复启动；先恢复游戏的正常页面。

运行条件

保持 Mac 唤醒、解锁，游戏在主显示器上可见，不被其它窗口遮挡。
运行期间不要移动或调整农场窗口，也不要同时手动操作游戏或启动第二个监控。
模板根据已验证的游戏画面制作；如果游戏改版或布局明显不同，识别可能需要更新。

个人配置和日志

每台电脑各自的数据默认保存在：
  ~/Library/Application Support/QQFarmMonitor

其中 config.json 是本机配置，farm.log 是监控日志，friends-status.json 是
最近一轮的匿名操作和状态记录。默认 region=null，启动时自动寻找农场窗口。
interval_seconds=180 表示每轮扫描结束后的等待秒数。

环境变量 QQFARM_DATA_DIR 可以把个人数据移到其它目录。通常不用设置；
需要时在终端设置后运行完整的启动文件路径。目录含空格时要用引号包住。
不同使用者不会通过此分享包共享个人配置、日志或账号凭证。

只检查或只运行一轮

在解压出的“QQ农场监控-Mac”目录打开终端，可运行以下命令：
  zsh portable_bootstrap.sh --diagnose
  zsh portable_bootstrap.sh --check
  zsh portable_bootstrap.sh --once

这些入口也会准备或复用依赖。--diagnose 只检查依赖、权限与窗口，
不会打开或操作微信；--check 在登录引导后只识别游戏，不点击采摘；
--once 完成一轮巡查后退出。首次安装依赖仍需要联网。

验证范围

分享者已在自己的 Mac 上确认全好友巡查和自动采摘可以运行。
此分发版通过 69 项自动测试与 15 项启动安装模拟场景，并完成了打包名单、
默认配置、启动文件权限与中文空格路径解压检查；

建议首次使用时在旁观察一轮，确认标识与拜访按钮对应正确。
